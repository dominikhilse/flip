How these hold together

One system, four screens

Whose colour

On the handoff and results a single player owns the moment, so their hue drives name, avatar ring, buttons and highlight. In Settings no one player is active, so chrome falls back to the brand terracotta; each player still wears their own hue in the roster.

Type, everywhere

Crimson Pro carries every name, score and title (lining + tabular numerals); Overpass carries every label, control and body line. No third face enters the flow.

Same frame

Identical 322px device shell, status bar, radii, dashed dividers and pill buttons as the Play screen — these read as the same app, not four mockups.

Both themes

Shown dark to sit beside the Play screen; each inverts to the light ground on the same tokens, and the overpay flip only swaps chrome — player hues stay put.

Only app/avatars/05.png (Mia) and 12.png (Theo) exist so far — Sam falls back to a colour + monogram circle, which is also the intended default before a player picks an avatar. Drop in the remaining avatars and they slot straight into these same rings.
