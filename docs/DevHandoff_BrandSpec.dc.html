Part 1 · Brand spec

The system, in brief

Name
Flip the Number

Kept. The flip verb still describes the tile action; the retired mascot pun costs nothing to drop. Zero repo/URL churn. Charm lives in the wordmark + Spudling sidekicks, not the words.

Feel
Warm, handmade, sturdy

Storybook burlap world. Chunky rounded numerals, soft tiles, generous radii. Playful but legible — kids at a shared phone.

Themes
Dark root + light

Dark is :root; .theme-light overrides. Overpay XOR-flips the effective theme as its signal — player hues stay constant, only chrome flips.

Mascots
Spudlings, as sidekicks

Splash / loading / wordmark, never gameplay chrome. Original apparel only. Tiles stay plain numerals — characters and numbers are separate systems.

Player palette — the 8 CVD-safe

Replaces the ad-hoc 12 in the current theme.js. Warm-leaning, mid-value, spaced by hue and lightness. Each hue ships a dark partner (edge) used as tile border + light-fill numeral — a second, non-hue channel of identity that also survives the theme flip.

Tile state & type

Open tile
Full-chroma · cream/edge numeral

Player hue fill, dark-partner border, numeral in cream or the edge shade — whichever clears 4.5:1.

Closed tile · 3 redundant cues
Desaturate + press + hollow

Drops toward grey #5c625f, inset shadow (pressed), dim hollow numeral. Any one cue reads state without colour.

Part 3 · Drop-in tokens

Code-ready

Two edits. theme.js gets the new palette object; style.css gets the font links + a few token additions. The existing chrome tokens (--bg/--fg/--border…) and the overpay XOR logic in applyTheme() are unchanged — player hues live outside that system on purpose.

A · app/theme.js — replace window.THEME

// The ONLY place tile/player colours live. { fill, edge, ink } per tile:
// edge = dark partner (border + numeral on light fills); ink = numeral.
window.THEME = {
  tileColors: {
     1:{fill:'#D34D4D',edge:'#99302F',ink:'#FBF5E9'},  // Chili
     2:{fill:'#E5842A',edge:'#A45610',ink:'#3A2408'},  // Marigold
     3:{fill:'#E4BE2F',edge:'#9C7F16',ink:'#3A2E06'},  // Honey
     4:{fill:'#7E9E38',edge:'#4C641F',ink:'#FBF5E9'},  // Moss
     5:{fill:'#26A69A',edge:'#146B62',ink:'#FBF5E9'},  // Teal
     6:{fill:'#3D7BC0',edge:'#21507E',ink:'#FBF5E9'},  // Denim
     7:{fill:'#6A5AC8',edge:'#3E3583',ink:'#FBF5E9'},  // Indigo
     8:{fill:'#B45699',edge:'#77335F',ink:'#FBF5E9'},  // Plum
     // 9-12: graceful, NOT CVD-safe. Avatar + name disambiguate.
     9:{fill:'#A65E38',edge:'#6E3A1F',ink:'#FBF5E9'},  // Rust
    10:{fill:'#6CB7E2',edge:'#2E6E96',ink:'#0E2A3A'},  // Sky
    11:{fill:'#E08AA1',edge:'#A24C63',ink:'#3A1420'},  // Rose
    12:{fill:'#8CA07D',edge:'#56674A',ink:'#1E2617'}   // Sage
  },
  // Closed tile ignores hue: desaturate + darken (fill), pressed inset in CSS,
  // dim hollow numeral (ink). One non-hue cue is enough on its own.
  closedTile: {fill:'#5C625F', edge:'#3F4442', ink:'#9AA19D'},

  // Player picker draws from the tile fills, in the safe-first order above.
  playerColors: ['#D34D4D','#E5842A','#E4BE2F','#7E9E38','#26A69A',
                 '#3D7BC0','#6A5AC8','#B45699','#A65E38','#6CB7E2',
                 '#E08AA1','#8CA07D'],
  playerNameTextColor: '#FBF5E9'
};

Migration note: tile values change from a flat string to {fill,edge,ink}. The tile renderer sets background fill, a 3px border edge, and text ink; the old tileTextColor / closedTileTextColor globals are folded into per-tile ink. If you'd rather not touch the renderer yet, keep the strings and add edge/ink as a parallel map — but the object form is the intended shape.

/* body uses the UI face; numerals/titles/primary buttons use display */
html, body { font-family: var(--font-ui); }
h1, .die, .tile, button.primary { font-family: var(--font-display); }
.tile        { border-radius: var(--radius-tile); }
.tile.closed { box-shadow: var(--tile-closed-shadow); }  /* + fill/ink from THEME.closedTile */
button.primary, button.secondary { border-radius: var(--radius-btn); }

The dice-roll wobble (.die.rolling, M10) and the cqh-based tile font sizing already in style.css are compatible and untouched — Bagel Fat One just makes the numerals read chunkier at the same sizes.

What changes, what doesn't

Changes

  • theme.js palette → new 8+4 with edge/ink
  • Fonts: Bagel Fat One + Figtree via <link>
  • Tile renderer: border + per-tile ink; closed = inset
  • Setup → tabbed menu (Players/Rules/App/Dev)
  • Play: Pause corner button (P0 escape)
  • Restart match + confirm guards (P1)

Stays exactly as-is

  • Dark-root / .theme-light structure
  • Overpay XOR in applyTheme()
  • Turn card + launch fixed contrast
  • Rules engine, motion thresholds, boost model
  • M10 dice wobble + cqh tile sizing
  • No Undo/Redo — dropped per playtest

Open / needs a call

  • Pause sheet contents (Resume / Settings / Restart / End)
  • Spudling wordmark asset for launch (Nano Banana)
